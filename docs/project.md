# Паспорт проекта: tg-search (TG Search)

## 1. Цель и ценность
- **Что делает:** десктоп-приложение для macOS, которое ищет лиды в Telegram поиском самого Telegram, квалифицирует сообщения ИИ и ведёт переписку (вручную или автопилотом).
- **Для кого:** Кирилл и его рабочие аккаунты; первый пилот — клиенты на разработку и автоматизацию.
- **Польза:** поток тёплых запросов без ручного мониторинга чатов.
- **Референс:** SignalDesk из поста @bimluck в Threads (разбор в чате BB, не в репозитории).

## 2. Текущий статус
- **Статус:** в разработке, MVP
- **Дата старта:** 2026-10-20
- **Текущий этап:** каркас и контракты готовы, модули пишутся параллельно (Composer 2.5 в git worktree)

## 3. Стек и инфраструктура
- **Среда:** Electron 44 + TypeScript 7 + React 19 (electron-vite 6), Vitest 5
- **Telegram:** TDLib 1.8.67 (`tdl` 8 + `prebuilt-tdlib`), отдельная сессия на каждый рабочий аккаунт
- **Хранилище:** `node:sqlite` (встроен в Node 24 внутри Electron), файл в userData
- **ИИ:** OpenAI-совместимый API, по умолчанию OpenRouter + `anthropic/claude-haiku-5.5`
- **Устройство:** Mac mini (разработка и запуск)
- **Репозиторий:** https://github.com/VKirill/tg-search (публичный)
